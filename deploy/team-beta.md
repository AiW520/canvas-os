# 受邀团队内测交付

当前范围：小规模可信团队、共享素材。PPT、画布位置、媒体节点和冻结版本仍保存在每位用户的浏览器中；不支持跨设备同步、同时编辑同一草稿或面向公众的用户隔离。服务仅监听回环地址，不能直接开放 Python 端口到公网。

## 首次部署

1. 在部署主机安装 Python 3.11+。复制项目代码（不要复制 `qa`、`tests` 和开发机账号数据）。配置独立且持久的 `CANVAS_AUTH_DB` 和 `CANVAS_ASSET_DIR`，赋予服务账号读写权限。
2. 先运行 `python server.py --port 4195`，在部署主机浏览器初始化管理员。进入管理台关闭公开注册。不要在未初始化时开放外部入口。
3. 安装 Tuzi 图片生成组件；设置 `CANVAS_IMAGE_SCRIPT` 为组件的 `generate_image.py` 绝对路径，`TUZI_CODING_API_KEY` 通过服务进程环境注入。不要写入网页、仓库或日志。组件固定使用 coding 通道、gpt-image-2。`--status` 只检查配置，不验证余额或真实生成。
4. 配置 `CANVAS_PUBLIC_ORIGIN=https://实际域名`。如需文本 AI，配置 `CANVAS_TEXT_AI_HOSTS` 为允许的 HTTPS 服务域名，多个以英文逗号分隔；团队模式仅允许这些域名的 443 端口。不配置则不开放文本转发。
5. 通过服务管理器运行 `python server.py --port 4195 --team`，设置失败重启、开机启动、持久工作目录和受限服务账号。不要并行运行多份实例指向同一个素材目录。
6. 在同一主机部署 Caddy，参考 `Caddyfile.example` 替换域名。配置 DNS 和 TLS，外部只开放 443（按证书签发需求开放 80），不开放 4195。保持原始 Host，应用不信任任意 `X-Forwarded-*` 头。
7. 用实际 HTTPS 域名登录管理员，运行“内测上线检查”，生成单次邀请后由管理员自行发送。邀请 72 小时有效，注册成功即失效，新账号只能成为成员。邀请本身是访问凭证，服务器只保存哈希。

## 首次验收

- 新成员经邀请注册、重复邀请失败、撤销邀请失败、停用账号会话失效。
- HTTPS 登录 Cookie 含 Secure / HttpOnly / SameSite，错误 Host 和跨站 POST 被拒绝。
- 中文图片生成、画布显示、加入 PPT、冻结预览、离线 HTML/ZIP 导出；需在服务商配置正确后人工执行一次真实生成。本轮自动回归只使用模拟服务，不扣费。
- 请求超时先使用“查看上次生成结果”。相同请求 ID 不会重新提交付费生成。进程在生成中崩溃时，结果会保守标为未确认，应检查服务商记录后决定是否新建请求。
- 至少在目标机器以预期人数和素材大小做负载测试。目前未承诺并发用户数或帧率。

## 备份与恢复

管理台“完整备份”包含当前浏览器草稿和素材，不包含用户数据库，也不包含其他成员浏览器的草稿。各成员需定期导出自己的项目。

发布前安排维护窗口：停止应用写入后，把 `CANVAS_AUTH_DB` 数据库、整个 `CANVAS_ASSET_DIR` 和各成员的项目导出保存到受限备份位置。账号库含密码哈希、会话和邀请记录，不能公开下载。保留环境配置的变量名，密钥单独由凭据系统管理。

恢复演练在独立目录和端口执行：恢复数据库和素材，先本机启动验证账号及媒体引用，再导入 PPT 项目。恢复后撤销历史会话和未使用邀请；不要直接用旧数据库覆盖运行中的服务。当前没有全工作区一键恢复入口。

## 尚未验收的发布条件

真实部署主机、域名/TLS、服务守护、异机邀请注册、服务商成功生成、备份恢复演练与负载测试。配置模板不代表已部署。这一版本适合受控内测，不应按多租户公网 SaaS 发布。
